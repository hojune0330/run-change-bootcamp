확인했습니다. 이 공개 프리뷰는 여전히 운영 서비스와 연결된 파일럿이 아닙니다.

## 고정 측정안

- 공식 성과 측정: 3,000m
- 공식 기준 측정: 2026-08-27
- 공식 재측정: 2026-10-15
- RHR 기준 기간: 2026-08-17 ~ 2026-08-23
- RHR 비교 기간: 2026-10-08 ~ 2026-10-14
- RHR 유효 최소 일수: 각 기간 3일
- 유효 3K 전후 쌍 최소 15명, 프로토콜 준수율 80% 이상
- RHR은 탐색적 보조지표이며 의료 진단, 인과 효과, 직원 순위로 해석하지 않음

현재 공개 시드 데모에는 과거의 12분·3K·5K 선택 화면이 남아 있습니다. 파일럿 보고의
기준은 위의 고정 3K·RHR 계약이며, 공개 데모의 선택 화면을 최종 측정안으로 설명하지 않습니다.

## 클라이언트 데모 순서

6개 화면·동작 안에서 설명합니다.

1. 공개 URL을 열고 시드 데모와 실제 운영의 차이를 먼저 고지합니다.
2. 참가자로 시작해 오늘 할 일과 프로그램 안내를 봅니다.
3. 기록 화면에서 수동 입력·검토 초안 흐름만 설명합니다.
4. 변화 화면에서 전후 비교 목적을 설명하되 효과를 확정해 말하지 않습니다.
5. 첫 화면으로 돌아와 데모 데이터를 안전 초기화할 수 있음을 보여 줍니다.
6. 코치로 시작해 코호트 현황과 승인 중심 운영 방향을 보여 줍니다.

## 검증 결과

- 타입 검사와 린트 통과
- 단위 테스트 346개, 통합 테스트 15개, 배포 계약 테스트 4개 통과
- PostgreSQL 17.10에서 신선 설치, 업그레이드, 역할 행렬, 함수 경계, 정적 보안 검사 통과
- 인증 마이그레이션의 신선 설치·업그레이드와 retained-JWT 차단 시나리오 통과
- 인증 브라우저 시나리오 18개 중 14개 통과, 화면 조합상 의도된 4개 스킵
- 로그인·로그아웃·네트워크 복구 화면 13장과 실행 트레이스 18개 확보
- Pages 후보 산출물의 실제 브라우저 배포 시나리오 6개 통과
- 공개 URL은 200 응답, PLUS Run 브랜드 식별, 모바일·데스크톱 표시와 수평 overflow 없음, 콘솔 오류 없음을 확인했으며 공개 번들은 로컬 빌드와 SHA-256이 일치

## 아직 하지 않은 것

- 호스팅 Supabase, 운영 도메인, 운영 시크릿, 실제 이메일 전달, 실제 계정은 연결하지 않았습니다.
- 실제 직원 초대는 활성화하면 안 됩니다. 개인정보 책임자 승인, 대상자 명단, 동의문,
  보존 기간, 지원 연락처가 확정된 뒤 별도 운영 승인을 받아야 합니다.
- 참가자 Q&A·소셜·파일 가져오기·스크린샷 AI·변화 화면과 코치·관리자·알림·삭제 흐름은
  데이터·보안 계약의 기반이 있으나 모두 운영 화면과 호스팅 서비스에 연결된 상태는 아닙니다.
- Wave 2(Task 8~16) 운영 기능은 아직 운영 화면과 호스팅 서비스에 완전히 연결되지 않았습니다.
- AI는 동의와 ZDR 확인이 없으면 호출하지 않는 fail-closed 상태이며 자동 게시하지 않습니다.
- 직원 평가, 순위화, 의료 진단, 인과 효과, 민감한 개인 건강값의 이해관계자 공개는 범위 밖입니다.

## 클라이언트가 결정할 항목

1. 파일럿 대상: 참가자 수, 코치 수, 관리자와 보고 수신자
2. 지원 기기: 사내 PC, 개인 휴대폰, iOS·Android 최소 버전
3. 측정안 승인: 고정 3K 일정, RHR 착용·결측 기준, 성공 판단 기준
4. 운영 책임: 초대 승인자, 개인정보 책임자, 문의 창구, 사고 대응 담당자
5. 데이터 원칙: 수집 항목, 보존 기간, 삭제 시점, AI 사용 여부
6. 공개 방식: 기존 시드 데모 유지 또는 별도 초대 전용 파일럿 도메인

이 여섯 가지가 확정되기 전에는 실제 직원 초대나 운영 데이터 연결을 시작하지 않습니다.
